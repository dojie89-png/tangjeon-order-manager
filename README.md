# 케이진 탕전주문 관리

Python/Tkinter 기반 탕전주문 관리 도구입니다.

## 작업 규칙

- `order_export_gui.py`는 항상 최신 작업본입니다.
- 안정 버전은 `versions/order_export_gui_v*.py`에 복사본으로 보관합니다.
- 변경 이력은 Git 커밋으로 함께 남깁니다.

## 현재 기준 버전

- `order_export_gui.py`: `order_export_gui_v12.36.py`에서 가져온 최신 작업본
- `versions/order_export_gui_v12.36.py`: v12.36 스냅샷

## 실행 전 패키지

```bash
pip3 install -r requirements.txt
```

## 기본 검증

```bash
python3 -m py_compile order_export_gui.py
```
